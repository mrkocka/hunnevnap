# HunNévnap

Magyar dátumot, folyamatosan frissülő pontos időt és az aktuális névnapokat megjelenítő Elementor widget WordPresshez.

## Funkciók

- Dátum, idő és névnap külön kapcsolható megjelenítése
- A WordPress webhely időzónájának használata
- Másodpercenként frissülő pontos idő
- Függőleges és vízszintes, reszponzív elrendezés
- Külön szín- és tipográfiabeállítás a dátumhoz, időhöz és névnaphoz
- Állítható igazítás és elemköz
- Helyben tárolt magyar névnapadatok
- Nincs külső API és adatgyűjtés

## Követelmények

- WordPress 6.5 vagy újabb
- PHP 7.2 vagy újabb
- Elementor 3.5.0 vagy újabb

## Nyelvek

A plugin forrásnyelve angol, és teljes magyar (`hu_HU`) fordítást tartalmaz. Magyar nyelvű WordPress-webhelyen a widget kezelőfelülete automatikusan magyarul jelenik meg.

## Telepítés

1. Töltsd le a repository tartalmát.
2. A plugin fájljait tartalmazó `hun-nevnap` mappát másold a WordPress `wp-content/plugins` könyvtárába.
3. Aktiváld a HunNévnap bővítményt.
4. Az Elementor szerkesztőben keresd meg a **HunNévnap** widgetet.
