Magyar dátum, folyamatosan frissülő pontos idő és névnap Elementor widgetként.

== Description ==

A plugin egy „HunNévnap” widgetet ad az Elementor Általános kategóriájához. A widget a WordPress webhely időzónája szerinti dátumot, pontos időt és az adott naphoz tartozó magyar névnapokat jeleníti meg.

Az Elementor szerkesztőben külön kapcsolható a dátum, az idő és a névnap. Beállítható az igazítás, a tipográfia, a színek és a térköz is.

* Nem használ shortcode-ot.
* Nem használ külső API-t.
* Nem továbbít és nem gyűjt adatot.
* A névnapadatokat helyben, a plugin tartalmazza.

== Installation ==

1. Telepítsd és aktiváld az Elementor bővítményt.
2. Másold a plugin mappáját a `/wp-content/plugins/` könyvtárba.
3. Aktiváld a HunNévnap bővítményt.
4. Az Elementor szerkesztőben keresd meg a „HunNévnap” widgetet.
